# Resources Model (Deferred)

**Last updated:** 2026-03-06

This document is retained as a deferred concept from the earlier MVP direction.

## Active status

The active v0 MVP is centered on:

- projects (existing local git repos)
- tasks (accountability objects)
- sessions (execution surfaces)

Resources are not part of that active core.

## What still survives conceptually

- Durable git-backed code and documents may still become reusable context later.
- Sessions may eventually load project-owned knowledge artifacts in a more explicit way.
- Search/index layers can still be derived from working copies rather than treated as primary source of truth.

## What is intentionally deferred

- standalone resource ownership rules
- resource creation flows
- resource provenance schema
- attach/detach behavior and shared-resource linking

## Revisit trigger

Return to this topic after the project/task/session core is stable enough, and only if real usage shows the need for a separate durable-output layer.
