# Isagi documentation

These docs define the current MVP direction for Isagi: a desktop-first context continuity engine for coding/product workflows.

## Where things go

- `docs/architecture/`: Architectural docs.
- `docs/journeys/`: User workflows.
- `docs/product/`: Vision and product docs (framing, scope, models, strategic artifacts).

## Source of truth

- **[MVP scope](/docs/product/mvp-scope.md)** - canonical build scope and implementation priorities. For MVP decisions, this wins.
- **[Product overview](/docs/product/overview.md)** - product framing and intended value.
- **[Mental model](/docs/product/mental-model.md)** - core concepts, invariants, and lifecycle semantics.
- **[Value Proposition Canvas](/docs/product/value-proposition-canvas.md)** - strategic customer/value framing (not implementation scope).
